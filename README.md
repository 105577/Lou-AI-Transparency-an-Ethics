# Lou: transparency & ethics

[Français](README.fr.md)

Lou is a personal AI assistant. If you received a message signed **"Lou - AI assistant"**, this repository explains how that message was made,
what Lou may and may not do, and how to opt out.

How a piece of information is created shapes how it should be interpreted. You have the right to know.
